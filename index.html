🆕 2026 年新規定

免費版帳號「終生」只能下載 7 次歌曲的 MP3

自 2026 年起，Suno AI 免費版除了原本的每日 50 credits 之外，另新增「下載次數」的終生上限： 每個免費帳號一輩子總共只能下載 7 次歌曲的 MP3 檔案。 次數用完後，即使每天仍有 50 credits 可以生成、可以在網站上聆聽， 也無法再把歌曲下載成 MP3 存檔，必須升級 Pro / Premier 付費方案才能繼續下載。

終生下載額度：已用 0 / 7 ・ 剩餘 7 次
課堂提醒：因為只有 7 次機會，請先在網站上把兩個版本都聽完、確定要哪一首之後再按下載， 不要每生成就下載一次。課堂作業（一首歌 ＋ 一支影片配樂）建議至少保留 2～3 次額度備用。
小撇步：「聆聽／生成」與「下載」是兩套獨立額度——生成看每日 credits（50/天），下載看終生次數（7 次）。 所以你可以每天生成、反覆比較，只把最終選定的那一首下載下來。

Unit 1 · Station 02

操作介面模擬器：Prompt 模式 vs Custom 模式

Suno AI 的創作方式非常簡單：在腦中構思題材，點進側邊欄的 Create 就能開始。 下面是依教材重建的可操作模擬介面，切換模式、填寫欄位、按下 Create 看看會發生什麼事。

模式 A

Prompt 模式（預設）

創建新歌的默認模式，只需輸入一個欄位：Song Description 音樂描述。 點擊側邊欄 Create 預設就會是 Prompt 模式。

  • 區塊：選擇模式（Custom）/ 選擇版本（v3…）/ Song Description / Instrumental 切換
  • 適合：快速產出、讓 AI 自行發揮歌詞與結構
模式 B

Custom 自訂模式

可設定音樂風格、自訂歌詞、歌曲名稱，把創作主導權拿回自己手上。

  • Lyrics：輸入背景或關鍵字後按 Surprise Me（新版為 Write with Suno）協作生成歌詞
  • Instrumental：人聲演唱與純音樂切換，開啟時為純音樂演奏
  • Style of Music：指定音樂類型，可參考系統提供的提示
  • Exclude Styles：排除不想要的風格（drone metal、beatboxing、melodic hardcore…）
  • Title：歌曲名稱

Unit 1 · Station 04

流行歌曲的結構地圖

在 Custom 模式寫歌詞時，用 [Verse]、[Chorus]、[Bridge] 等標記， Suno 就能理解段落配置。點擊下方色塊認識每一段，或按「▶ 播放順序」看完整安排。

一首歌的常見配置：Intro → Verse → Pre-Chorus → Chorus → Inter → Solo → Bridge → Outro

[Verse 1]北方的風，吹過那片山 硝煙的雲，遮住家鄉的暖 [Chorus]蛋香飄，戰火燃 平凡的願望卻換來永別的寒 [Bridge]黃金般的米粒，滿是人間煙火 [Outro]一碗蛋炒飯，在歷史裡沉澱

以上取自教材中 ChatGPT 協作生成的《蛋炒飯》歌詞，加上段落標記就能直接貼入 Custom 模式的 Lyrics 欄。

用 ChatGPT 協作創作歌曲

💬 教材實錄還原：從一句提問到一首完整的歌

以下重現教材中的對話流程（題材具歷史與情感衝擊，課堂上僅作為「提問 → 風格建議 → 歌詞產出」的技法示範）。

1️⃣

提問：給出題材，並請 AI 推薦適合的音樂風格

我
我想寫一首具有歷史與情感衝擊題材的敘事歌曲（教材示例：以歷史人物與日常食物形成的強烈對比為題），並請推薦適合這首歌的音樂風格。
AI
這是一個非常特別且具有歷史與情感衝擊的題材，以下是建議的創作方向與適合的音樂風格：

歌曲創作方向
1. 叙事風格：以敘事方式描述事件與代價，並融入歷史背景的緊張氣氛與個人情感。
2. 對比手法：用日常場景與戰爭的殘酷形成對比，凸顯人性的脆弱與荒誕。
3. 情感層次：從平凡的渴望到生命消逝的過程，加入對歷史、命運和家庭的反思。
技巧解析：提問時同時要「題材」＋「請推薦音樂風格」，AI 就會一次給你創作方向與可貼進 Suno 的 Style 關鍵字。
2️⃣

AI 回覆：四種適合的音樂風格（含代表範例）

風格 1

悲劇敘事民謠

以吉他或琵琶等樂器為基礎，輕柔的旋律配合低沉的嗓音，營造感傷的敘事感，如中國民歌風格或現代民謠。

代表範例：《南山南》（馬頔）

風格 2

新古典鋼琴與管弦樂

用鋼琴和弦樂帶來莊嚴的氛圍，強調歷史的重量感與生命的無常。

代表範例：《菊次郎的夏天》（久石讓）

風格 3

中國風搖滾

想增強戲劇性時加入搖滾元素，以大鼓和笛子點綴，增強情感爆發力。

代表風格：鄭鈞、汪峰的作品

風格 4

諷刺性電子音樂

想表現荒誕感，可用電子音樂和不協和的聲音效果，反映歷史的諷刺意味與人性的荒謬。

結構與樂器搭配建議：① 開場用柔和的鋼琴或古箏，營造和平日常的氛圍；② 中段加入緊張感的鼓點或戰爭聲效，象徵戰爭的侵入與悲劇性轉折；③ 最後用低沉的和弦或單一樂器結尾，留給聽眾深思的空間。
3️⃣

追問：「請幫我寫歌詞」→ 產出完整歌詞

我
請幫我寫歌詞
AI
以下是以敘事風格創作的歌詞，呈現故事同時帶有情感與歷史反思。
生成歌曲：《蛋炒飯》（含 Verse 1 / Chorus / Verse 2 / Chorus / Bridge / Final Chorus / Outro 七段）
（Verse 1）北方的風，吹過那片山， 硝煙的雲，遮住家鄉的暖。 前線的帳篷，短暫的平安， 一碗蛋炒飯，是他簡單的期盼。 （Chorus）蛋香飄，戰火燃， 平凡的願望卻換來永別的寒。 一顆炸彈，鋪滿天， 問蒼天，為何英雄也難敵人間？ （Verse 2）父親的目光，從未有溫暖， 革命的路，血與汗鋪滿。 他說「報國」，便不顧一切向前， 可那一碗蛋炒飯，誰料成了遺願？ （Chorus）蛋香飄，戰火燃， 平凡的願望卻換來永別的寒。 一顆炸彈，鋪滿天， 問蒼天，為何英雄也難敵人間？ （Bridge）黃金般的米粒，滿是人間煙火， 炸彈劃破夜空，帶走一顆赤子心。 廚房裡的溫暖，變成永恆的追問， 蛋炒飯的香味，卻再也回不來了。 （Final Chorus）蛋香飄，戰火燃， 平凡的願望卻換來永別的寒。 一碗飯，這麼簡單， 卻埋葬了青春，埋葬了明天。 （Outro）北方的風，吹過那片山， 誰還記得，那平凡的期盼？ 一碗蛋炒飯，在歷史裡沉澱， 多少笑與淚，都融進這碗飯間。
⚠️ 課堂提醒：此例僅示範「提問結構 → 風格建議 → 歌詞產出」的工作流。實際創作請選擇合適、尊重他人與史實的題材。
4️⃣

最後一步：把成果搬進 Suno AI 生成歌曲

  1. 切換到 Custom 自訂模式。
  2. 把 ChatGPT 寫好的歌詞貼進 Lyrics（可加上 [Verse] / [Chorus] 段落標記）。
  3. 把推薦的音樂風格貼進 Style of Music，例如：悲劇敘事民謠、鋼琴與弦樂、中國風搖滾。
  4. 不需要的人聲或風格寫入 Exclude Styles；純演奏則開啟 Instrumental。
  5. 填上 Title（例：蛋炒飯）→ 按 Create → 聆聽兩個版本 → 確定後才下載存檔（免費版終生僅 7 次）。
Unit 2 · Station 06

如何講故事？撰寫腳本的重點

影片製作流程 → 影片後製流程 → 腳本撰寫。腳本格式可參「生成式 AI 影片報告單」， 可自行撰寫，亦可請 AI 幫你撰寫。以下是老師的指示詞與 ChatGPT 產出的短片腳本：除夕之夜。

★ 老師的指示詞（Prompt）

短片腳本：除夕之夜
開場要吸引人，結尾要引人深思，從女性獨立的角度出發。
請以表格形式細化腳本，欄位包含：分段、內容、使用配樂、預估秒數。
指示詞設計三要素：① 明確主題（除夕之夜）；② 敘事要求（開場吸引人、結尾引人深思）；③ 觀點與輸出格式（女性獨立角度、表格化分鏡）。

  1. 開場用女主角的內心獨白快速吸引觀眾共鳴。
  2. 婆媳矛盾與婚姻問題是劇情衝突的核心，透過對話與細節展示情緒張力。
  3. 結尾的陽台場景隱喻新生活的開端，結合背景音樂提升觀眾情緒的觸動感。
  4. 音樂選擇偏向鋼琴與弦樂，烘托情感起伏並支持女性自我重生的主題。
◎ 上面內容為 ChatGPT 生成的腳本內容，配樂部分只要用一首 AI 歌曲串連就可以了！（也就是第一單元用 Suno 生成的那首歌）

🎬 影片製作流程

  1. 構思主題與故事大綱（要講什麼故事？給誰看？）
  2. 撰寫／AI 生成腳本與分鏡（含秒數、對白、配樂）
  3. 蒐集與生成素材（文本、圖像、動畫、音效、語音）
  4. 進入剪輯軟體（剪映）排列時間軸
  5. 後製：字幕、轉場、色彩、音量平衡
  6. 匯出影片，取得完整成品檔案

🛠️ 影片後製流程

  1. 粗剪：素材排序、裁掉多餘片段
  2. 音樂對齊：音軌與影片軌道完全對齊，避免影音不同步
  3. 字幕：自動歌詞 → 校正 → 字形與顏色調整
  4. 效果：轉場（光暈、模糊、淡入淡出）、色彩調整、圖層與遮罩
  5. 預覽檢查：邊播放邊確認字幕與節奏
  6. 匯出設定 → 下載成品檔案
Unit 2 · Station 07

生成式 AI 影片素材蒐集

四大類素材 ＋ 蒐集四步驟，以及「飲食文學」影片製作參考方向。

文本素材

生成影片時，文本是許多 AI 工具的核心輸入。

  • 劇本或描述：用於生成對應的影片內容，例如場景描述、角色動作或故事情節。
  • 字幕或旁白：可直接生成，或用於後期配合影片。
  • 提示詞（Prompts）：清晰且詳細的提示詞，用於引導生成圖像或動畫。
對應工具：ChatGPT（腳本／歌詞／旁白稿）、Suno AI（歌詞）。

視覺素材

生成式 AI 需要參考或生成的圖像素材。

  • 基礎圖片：可供風格轉換（Style Transfer）或場景生成的參考圖片，例如角色設計圖、背景草圖。
  • AI 生成圖像：使用圖像生成工具（如 DALL·E、MidJourney）創建的背景、角色或物品圖像。
教材建議：一部影片約需準備 10 張圖片 + 1 首歌曲（剪映素材區匯入清單）。

音效與語音素材

生成式 AI 能製作或強化音效與語音。

  • 提示聲音：用於訓練 AI 模型生成特定語音或效果的參考音頻。
  • 背景音樂：AI 生成的音樂（如 Amper Music 或 AIVA），用於匹配影片節奏。
  • 語音生成素材：旁白文本，搭配 TTS（Text-to-Speech）工具生成自然語音。

影片後製素材不強制

AI 生成的影片通常需要後期處理來完善。

  • 轉場效果：例如光暈、模糊、淡入淡出的過渡模板。
  • 色彩調整工具：調整 AI 生成影像的色調，確保畫面一致性。
  • 圖層與遮罩：用於合成影片中的多個畫面或細節。

蒐集素材步驟

步驟說明
① 明確影片需求撰寫故事大綱、設定角色和場景。
② 準備提示詞與參考素材定義 AI 生成的具體風格或元素。
③ 使用多元工具結合圖像生成工具（製作背景或角色）＋ 動畫生成工具（讓靜態圖像動起來）＋ 語音與音樂生成工具（補充聲音素材）。
④ 後製整合將生成素材進行剪輯、調整和效果增強。
★ 小撇步：可以先將所有素材整理在一個資料夾內，匯入剪映時一次拖曳，效率最高。

🧪 時間軸小挑戰

  1. 目前的範例音樂只有 10 秒、影片有 12 秒 → 右下角會出現「影音未對齊」警告。
  2. 請選取最下方音訊軌的 ♪ AI 歌曲，拖右緣把手或按「＋ 拉長 0.5s」，把它拉到與影片等長。
  3. 警告變成 ✓ 已對齊 就成功了！
  4. 再試試：選取影片軌的「轉場動畫」按「＋ 拉長」→ 應該會被擋下並提示動畫只能縮減。
  5. 按 ▶ 播放，觀察最上方字幕軌、播放頭、預覽畫面三者是否同步。

🖱️ 操作提示

  • 左側工具列：媒體 / 音訊 / 文字 / 特效 / 轉場 / 濾鏡，點擊可切換素材區內容。
  • 素材區：點素材即可加入對應軌道（等同於拖曳至時間軸）。
  • 時間軸：點片段選取 → 下方可拉長、縮短、分割、刪除。
  • 刻度尺：每格 1 秒，紅色直線為播放頭，決定預覽區顯示哪一個畫面。
  • 字幕：最上方字幕軌對應預覽區下方的橘色白字，教材說明可直接點一下修改。

🚫 常見錯誤與解法

影音不同步音訊軌（最下方）沒有和影片軌完全對齊 → 拖曳至起點一致、長度相同。
字幕沒顯示字幕軌要放在影片軌之上才會疊加在畫面上。
動畫被拉壞圖片可往右拖曳拉長，動畫只能縮減，不能拉長。
字幕沒有涵蓋全片字幕軌比影片軌短 → 補上剩餘句段或延長最後一句。
字幕是簡體剪映內建只有簡體中文 → 先把歌詞轉成繁體另存文字檔，校正時複製貼上。
匯出有浮水印電腦版會出現商用提醒視窗，課堂作業可直接按提示按鈕繼續。
檔名亂取先把專案名稱改成影片名稱，匯出時就不用另外取檔名。
配樂還沒下載就開剪免費版 Suno 終生只能下載 7 次 MP3 → 先確定要用哪一首再下載。
